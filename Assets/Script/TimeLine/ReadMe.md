Timeline是一个抽象的概念
我把可以符合以下内容的逻辑抽象成timeline

首先开始和终止
有在某帧操作或者按时间操作，有指令记录

实际上某帧或者按时间都是指timeline的轨道时间链路的逻辑。也就是整个timeline是按照什么播放的(虽然叫timeline但不一定是完全按照时间播放？)

例如游戏行为录制回放是timeline (可以是以操作录制的也算是timeline 其实就是指令队列了，例如解密游戏就是一个按照操作排列的timeline)，动画一类的播放也是timeline

timeline依照复杂度有不同的逻辑，但是都是相当于只是把对应的操作或者数据写入逻辑的操作

整个timeline就是一个巨大的指令队列，只不过指令的发出时间比较不一样

其实生命周期也是一种会循环的timeline，之前使用管线系统构建生命周期，但是实际上可以再抽象一层timeline的系统，因为管线只有先后顺序却没有时间上的逻辑顺序。
